# Звіт з Лабораторної роботи №4: Розробка багатосторінкової навігації в React

## 1. Структура маршрутів та вкладені маршрути

У проекті реалізовано наступну структуру маршрутів за допомогою `react-router-dom`:
- `/` — Головна сторінка.
- `/feed` — Стрічка новин.
- `/feed/:postId` — Детальна сторінка конкретного поста.
- `/profile` — Профіль користувача.

**Вкладені маршрути для профілю:**
Реалізовано через компонент `Outlet` у `Profile.jsx`. У головному файлі `App.jsx` маршрут `/profile` має дочірні маршрути `/profile/info` та `/profile/settings`. Користувач автоматично перенаправляється з `/profile` на `/profile/info` за допомогою компонента `Navigate`.

## 2. Код: Використання useParams

Ось приклад того, як ми отримуємо ID поста з URL для відображення відповідного контенту:

```javascript
import { useParams } from 'react-router-dom';
import { posts } from '../data';

function PostDetails() {
  const { postId } = useParams();
  const post = posts.find(p => p.id === parseInt(postId));

  if (!post) return <h2>Пост не знайдено!</h2>;

  return (
    <div>
      <h1>{post.author}</h1>
      <p>{post.content}</p>
    </div>
  );
}
```

## 3. Відповіді на контрольні запитання

### У чому різниця між компонентами Link та NavLink?
- **Link** — це базовий компонент для навігації між сторінками без перезавантаження.
- **NavLink** — це спеціальна версія `Link`, яка автоматично додає клас `active` (або дозволяє задати стилі), коли поточний URL збігається з атрибутом `to`. Це ідеально для навігаційних панелей.

### Для чого потрібен компонент Outlet у вкладених маршрутах?
`Outlet` виконує роль "плейсхолдера" (placeholder). Він вказує батьківському маршруту, де саме в його шаблоні (Layout) потрібно рендерити дочірні компоненти.

### Як передати та отримати динамічний параметр з URL (наприклад, :id)?
Для передачі в `Route` використовується двокрапка: `path="post/:id"`. Отримати цей параметр у компоненті можна за допомогою хука `useParams()`, який повертає об'єкт із ключем `id`.

### Призначення хуків useNavigate та useLocation:
- **useNavigate** — дозволяє програмно змінювати URL (наприклад, після відправки форми або при натисканні кнопки "Назад").
- **useLocation** — повертає об'єкт поточного розташування (URL, шлях, параметри пошуку), що корисно для аналітики або умовної логіки на сторінці.

### Як реалізувати сторінку 404 за допомогою React Router?
Потрібно додати маршрут із шляхом `*` в самому кінці списку маршрутів:
`<Route path="*" element={<NotFound />} />`. 
Він буде активуватися, якщо жоден інший маршрут не збігся з поточним URL.
