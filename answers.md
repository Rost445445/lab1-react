# Відповіді на контрольні запитання

## 1. Чому ми використовуємо Vite замість Create React App у 2025 році?
Vite використовує **Native ESM** для обслуговування коду під час розробки, що дозволяє браузеру завантажувати лише необхідні модулі. Це забезпечує миттєвий запуск (Cold Start) та дуже швидку гарячу заміну модулів (HMR). CRA базується на Webpack, який вимагає повного перезбирання проєкту, що значно повільніше на великих проєктах. Також Vite використовує `esbuild` для попередньої збірки залежностей, що працює в рази швидше за аналогічні інструменти на JS.

## 2. Яка різниця між dependencies та devDependencies у файлі package.json?
*   **dependencies:** Пакети, необхідні для роботи програми у стандартному режимі (наприклад, `react`, `react-dom`). Вони потрапляють у фінальну збірку.
*   **devDependencies:** Інструменти для розробки, тестування та збірки (наприклад, `vite`, `eslint`). Вони не потрібні користувачеві в браузері і не включаються у фінальний бандл.

## 3. Для чого потрібен файл .gitignore і що туди обов'язково треба додати для Node.js/React проєкту?
`.gitignore` запобігає попаданню непотрібних або секретних файлів у репозиторій.
Обов'язково додати:
*   `node_modules/` (зовнішні залежності)
*   `dist/` або `build/` (результат збірки)
*   `.env` (секретні змінні)
*   `*.log` (логи помилок)
